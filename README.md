# Mini Investment Platform (Static)

Open `index.html` in a browser to view the homepage. Click "Invest Now" to open WhatsApp to contact the admin (number set in `js/data.js`).

Use `dashboard.html` to enter codes such as `INV10A`, `INV20B`, `INV50C`, `INV100D` to view investment details and request withdrawal. Currency displayed on the site uses Kina (`K`).

Edit `js/data.js` to add or change plan codes and returns.
